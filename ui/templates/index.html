THE METHOD, IN SEVEN STEPS

How VectorVibe Works

From seven slider values to a playlist ranked with Linear Algebra.

  1. 01

    Represent songs as vectors

    Each song’s seven numerical values are kept in the same feature order. That makes every song a point—or vector—in a seven-dimensional feature space.

    S = [Classical, Pop, Energetic, Peaceful, Romantic, Tempo, Mood]Each song vector S ∈ ℝ7
  2. 02

    Create the song matrix

    Place the 100 song vectors into one matrix. Every row is a song; every column is one of the seven musical features.

    M ∈ ℝ100×7100 rows: songs · 7 columns: features
  3. 03

    Create the user vector

    The seven slider selections form a user preference vector in that same feature order, so it can be compared directly with each song.

    U = [u1, u2, …, u7] ∈ ℝ7Values come from the current sliders
  4. 04

    Calculate similarity

    For each song vector Si, the engine calculates its dot product with U, both vector lengths, and cosine similarity.

    Si · U‖Si‖   and   ‖U‖cos(θi) = (Si · U) / (‖Si‖ × ‖U‖)
  5. 05

    Calculate alignment

    Vector projection shows the part of a song vector along the user’s preference direction. The displayed alignment score is cosine similarity: a measure of directional agreement.

    projU(Si) = ((Si · U) / (U · U))UProjection vector and cosine alignment are shown in the song analysis
  6. 06

    Rank all 100 songs

    The recommendation engine computes every song’s cosine similarity, then sorts the complete set from highest score to lowest.

    sim(1) ≥ sim(2) ≥ ··· ≥ sim(100)Sorted by cosine similarity
  7. 07

    Recommend the Top 10

    Only the ten highest-ranked songs are displayed as recommendations. The other 90 were still included in the comparison and ranking.

    Playlist = ranks 1–10Selected from the complete 100-song comparison
